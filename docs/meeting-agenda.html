Infrastructure we suggest & cost

Stack A — consolidated, 3 vendors, one dashboard, scale-to-zero everywhere. Everything is already Dockerized; only the GPU layer needed a real decision.

Service~ Monthly
Modal — serverless GPU (vLLM+LoRA), $30/mo free credit$0–10
Railway — backend + frontend + Postgres + Redis~$5
Cloudflare R2 — object storage, free egress~$0
Total — Stack A~$5–15/mo

~$40–70 → ~$5–15/mo, sustainable with no grant needed. No always-on GPU to forget to shut down — the biggest operational risk is engineered away.

Migration is almost all config: one file (object storage) gets a small S3 swap, one auth header for Modal, the rest is env vars. Dockerfiles carry over unchanged.

3

Ofek — domain & DNS via Wix

First question for Ofek: "Do you have access to the Manage DNS Records screen in the Wix dashboard for achvalgbt.org.il?" — everything follows from that.

Wix fully controls the domain's DNS (ns4/ns5.wixdns.net). Plan: put the app on a subdomain + add a link/button from the Wix site. Do not iframe-embed (breaks Google login & RTL). Ofek adds 2 DNS records we provide (~5 min); SSL is then automatic.

Talking points & the day after

  • No support after handover — the critical deliverable is a non-technical operator handbook (incl. LLM-rescue prompts).
  • Account & billing ownership — Achva has no legal entity (no amuta). Who holds the cloud account + card? (Aguda 580014058 / NUIS / org account.)
  • Privacy promise — is "no third-party / no text storage" binding? It gates serverless GPU & external storage.
  • Grant — Microsoft-for-Nonprofits via the Aguda is nice-to-have, not a prerequisite. Plan for the no-grant path.
  • Single point person (Ofek?) — confirm who, and what they can operate.
  • Model for the last 4 weeks — fold validated data into the rule layer (zero infra, Ofek-controllable) vs. retrain.
